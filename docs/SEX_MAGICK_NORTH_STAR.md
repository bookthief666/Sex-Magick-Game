# Sex Magick 2.0 — Product North Star

## Core fantasy

Sex Magick 2.0 should feel like an illicit occult arcade object: immediate enough to understand with the hands, strange enough to feel discovered rather than explained, and deep enough that mastery reveals a ritual structure underneath the reflex game.

The experience should not read as “Flappy Bird with occult graphics.” The underlying control simplicity is an advantage; the design task is to turn that simplicity into a vessel for risk, concentration, rhythm, ascent, transformation and replay mastery.

## Design pillars

### 1. Immediate bodily control

Every rite must feel crisp before it feels symbolic.

- Input response should be legible and fair.
- Collision truth must match the visible geometry.
- Deaths should feel attributable.
- The player should understand the control gesture through use, not documentation.
- Touch must remain reliable on a Fold 6 in both postures.

### 2. Two genuinely different rites

HEX and MONAS should not be skins over one movement model.

**HEX** is sharp, punctuated, risky and eventful. It is about navigating hazards, accumulating Gnosis, deciding whether to bank or enter the Void, and ascending the Tree.

**MONAS** is continuous, centered, meditative and velocity-based. It is about controlled hold/release flight, Coherence and Warp.

Shared infrastructure is good. Shared sensation is not automatically good.

### 3. Ritual progression that can be felt

Progression should change the world before the player reads a label.

The eight Sephiroth are not just difficulty tiers. They should become increasingly distinct through:

- motion vocabulary;
- screen texture;
- color/contrast;
- obstacle rhythm;
- audio/harmonic character;
- transition timing;
- event intensity;
- what is withheld as well as what is added.

KETHER should feel like arrival/transcendence through clarity and subtraction, not simply maximum noise.

### 4. Risk with readable consequence

The Gate/Void loop is strongest when the player immediately understands:

- what they have accumulated;
- what they can safely bank;
- what entering the Void risks;
- what survival earns;
- what failure costs.

The player should feel tempted, not confused.

### 5. Short-run purpose, long-run mastery

A run should always contain more than “survive until death.”

Use missions, power-ups, progression, Gate decisions, personal bests, Rite Board history, Sephirah transitions and milestone events to create a run arc.

A strong run should generate a story the player can recount: “I banked twice, entered Geburah with one Aegis charge, survived the Void, reached Binah, then died trying to force Kether.”

### 6. Psychedelic restraint

Spectacle is valuable only when it preserves readability and performance.

Prefer authored contrast over constant intensity. If every frame is maximal, no event can feel important.

Effects should have semantic roles:

- a graze should not look like a band ascent;
- a Void loss should not look like an ordinary collision;
- a MONAS Warp should not look like HEX Gnosis;
- KETHER should not look like “more Geburah.”

### 7. Sound as gameplay information

The game should become increasingly understandable by ear.

Differentiate:

- ordinary passage;
- near miss;
- Gnosis gain;
- Gate arrival;
- bank;
- Void entry;
- Void survival;
- Void loss;
- mission completion;
- power-up earn/use;
- Sephirah transition;
- MONAS perfect/centered passage;
- Coherence threshold;
- Warp.

Sound should support mobile speakers/headphones without becoming fatiguing.

### 8. Fast retry, low friction

The game is arcade-first. Death should not create menu friction that kills flow.

The player should be able to:

1. understand why the run ended;
2. see what they achieved;
3. notice meaningful progress/new bests;
4. retry almost immediately.

### 9. Mystery without obscurity

Occult terminology and symbolism are part of the identity, but the player should not need prior Qabalah/Thelema knowledge to understand the game rules.

The game can say MALKUTH, YESOD and KETHER while still clearly communicating speed, goals, risk and reward.

### 10. Mobile/foldable as a first-class canvas

The Fold 6 is not an afterthought.

Design must remain coherent across:

- narrow cover display;
- large inner display;
- live posture transitions;
- safe areas/cutouts;
- touch-only use;
- realistic mobile GPU fill rate;
- mobile audio policy;
- installed/offline/PWA scenarios where supported.

## What “better” means

A change is valuable when it produces one or more of the following without damaging the others:

- clearer control;
- stronger fairness;
- more tension;
- more mastery;
- stronger replay compulsion;
- richer run arcs;
- more readable progression;
- more coherent occult identity;
- stronger audiovisual feedback;
- better performance;
- better accessibility;
- less state ambiguity/technical fragility.

“More code,” “more particles,” “more modes,” and “more lore text” are not success metrics.

## Current strategic sequence

The current best plan after M35 is:

1. **M36 — first-run ritual onboarding and experiential comprehension.**
2. **M37 — reward/run-arc/result/retry polish.**
3. **M38 — deepen MONAS audiovisual and mastery identity.**
4. **Visual regression modernization** using tolerance-based screenshots rather than brittle exact hashes.
5. Continue audio/haptics/performance/PWA refinement where evidence identifies the highest-value gaps.
6. Consider a third rite only when HEX and MONAS feel complete enough that new breadth will not hide unfinished depth.

Antigravity may reorder or revise this sequence after a verified audit, but must state the player-value argument and evidence for doing so.

## Ambition

The target is a compact game that a player can start in seconds, but whose presentation and progression feel like descending into a strange machine and then ascending through it.

The best future version should be recognizable from a screenshot, recognizable from its sound, and recognizable from the rhythm of its controls. Its occult identity should emerge from the interaction itself rather than being pasted onto it.
